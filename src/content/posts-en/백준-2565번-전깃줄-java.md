## ✨ Why LIS works here

#### LIS is used to find the longest increasing subsequence in an array.

But it is difficult to think of why we should use LIS for this problem.

![](/images/velog/백준-2565번-전깃줄-java-02.webp)

Read A in order in the example and look at the matching B values.

They are **{8, 2, 9, 1, 4, 6, 7, 10}**.

To prevent the wires from crossing, remove the pairs **(1, 8), (3, 9), (4, 1)**.

The remaining array is {2, 4, 6, 7}.

> **In other words, avoiding crossing wires in this problem -> finding the longest increasing subsequence.**

That is the conclusion.

## ✔️ Recurrence summary

- Maintain a list and append a new value **if it is larger than the current last value**.
- Otherwise, **find the first position whose value is greater than or equal to it** and replace that value.

```java
if (number[i] > list.get(list.size() - 1)) {
    list.add(number[i]);  // 증가 수열 계속 이어가기
} else {
    // number[i]가 들어갈 위치를 찾아서 교체 (수열 유지)
    for (int j = 0; j < list.size(); j++) {
        if (number[i] <= list.get(j)) {
            list.set(j, number[i]);
            break;
        }
    }
}

```

- Since we sort in ascending order by the position on the left utility pole, we only need to compare values on the right.

## ✅ What if the input gets larger?

The current problem's input size is as follows.

> The first line gives the number of wires between the two utility poles. The number of wires is a positive integer no greater than 100.

Since there are at most 100 wires in this problem, nested loops take only about 10,000 operations. But with more wires, they could exceed the time limit.

In that case, **binary search** can dramatically reduce the time complexity.

## 🖥️ Solution code (Java)

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        //StringTokenizer st = new StringTokenizer(br.readLine());
        int input = Integer.parseInt(br.readLine());
        int[][] inputNum = new int[input][2];
        int[] number = new int[input];
        for(int i=0;i<input;i++){
            StringTokenizer st = new StringTokenizer(br.readLine());
            inputNum[i][0] = Integer.parseInt(st.nextToken());
            inputNum[i][1] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(inputNum, (a, b)->{
            if(a[0]<b[0]) return -1;
            else if(a[0]>b[0]) return 1;
            else return 0;
        });
        for(int i=0;i<input;i++) number[i] = inputNum[i][1];
        List<Integer> list = new ArrayList<>();
        list.add(number[0]);
        for(int i=1;i<input;i++){
            if(number[i] > list.get(list.size()-1)){
                list.add(number[i]);
            }
            else{
                for(int j=0;j<list.size();j++){
                    if(number[i] <= list.get(j)){
                        list.set(j, number[i]);
                        break;
                    }
                }
            }
        }
        System.out.println(input - list.size());
    }
}

```

---

## ⏰ Time complexity

- Nested for loops → **O(N²)** (feasible with at most 100 inputs).
- Binary search approach: O(N log N).
