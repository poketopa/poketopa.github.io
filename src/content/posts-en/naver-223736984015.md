## DFS (Depth - First Search)

## BFS (Breadth - First Search)

I keep confusing them, so I am writing this down.

![DFS / BFS fundamentals cover](/covers/naver/naver-223736984015-1.webp)

DFS: Follows the nodes connected to a particular node as deeply as possible until there are no more connected nodes.

BFS: Checks all nodes connected to a particular node, moving one level at a time.

DFS is simple to implement because it goes all the way to the end nodes, but its time complexity can increase when every possibility must be checked.

BFS checks all connected nodes one level at a time, so it performs much better than DFS when finding the minimum value for reaching a particular condition.

Let's write the most basic form of each and memorize the basic code structure.

## DFS combinations

Print the possible ways to select three numbers from the array [1, 2, 3, 4, 5].

```
import java.util.*;

public class Main {
public static void main(String[] args) {
int[] number = {1, 2, 3, 4, 5};
int[] visited = new int[number.length];
int length = 3;
List<Integer> list = new ArrayList<>();

for (int i = 0; i < number.length; i++) {
dfs(number, visited, length, i, list);
}
}

private static void dfs(int[] number, int[] visited, int length, int nowIndex, List<Integer> list) {
if (visited[nowIndex] == 1) return;

visited[nowIndex] = 1;
list.add(number[nowIndex]);

if (list.size() == length) {
System.out.println(list);
} else {
for (int i = 0; i < number.length; i++) {
dfs(number, visited, length, i, list);
}
}

visited[nowIndex] = 0;
list.remove(list.size() - 1);
}
}
```

## The visited array

Every index is initialized to 0, and the index of each value added to the list is changed to 1.

This then serves to skip numbers already in the list when recursively calling dfs

## 2. Recursion

Inside dfs, a for loop calls dfs again, creating recursion.

This code computes permutations (it considers the order of the combination's elements),

So the for-loop counter is set to int i = 0 to explore indices smaller than nowIndex,

But for combinations where order does not matter, it can be optimized by setting int i = nowIndex + 1.

## 3. Backtracking

When the condition (a list size of 3) is met, clear the visited record and remove the item from the list.

This code must be at the end of the dfs function.

Because all possibilities at the current index (nowIndex) must be checked before moving to the next index.
